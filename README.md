**PictureIt** is a multiplayer game prototype built in **C#** using the **Godot Engine**. Players are tasked with exploring dynamic environments to find and photograph specific locations based on reference images.

## ✨ Features

* **Photography Mechanics:** Players explore environments with a camera to match and capture target locations based on visual reference clues.
* **Peer-to-Peer Networking:** Integrated **WebRTC** for direct P2P connections between players without requiring a dedicated server host.
* **Lobby System:** Custom lobby setup allowing players to join via passcode and using public torrent servers for signaling and initial connection handshake.
